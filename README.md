# Dayprint (今日印迹)

> **Your life, in prints. 随手记、自动理、跨天活体演进、终身认知升维。**

Dayprint 是面向知识工作者、独立创作者与终身思考者的**活体记忆工作区与实体触感微手账（Tactile Living Memory Workspace）**。采用 Local-First 本地优先架构，将零碎思想即刻转化为热敏小票与画卷瀑布流，并通过 L0-L4 认知金字塔自动蒸馏周度记忆，静默归档至用户私有 GitHub 仓库，实现数据 100% 自主掌控。

---

## 快速开始 (Getting Started)

```bash
# 1. 安装依赖
pnpm install

# 2. 启动开发服务器
pnpm dev

# 3. 生产环境构建验证
pnpm build
```

本地浏览器访问：[http://localhost:3000](http://localhost:3000)

## 核心特色矩阵 (Core Highlights)

1. **实体热敏小票与撕纸微交互 (Tactile Thermal Slip & Audio)**：拟真锯齿边缘、物理撕纸动画与 Web Audio 机械按键及撕纸音效。
2. **今日手账画卷与瀑布流 (Editorial Scrapbook Stream)**：莫兰迪色标系统（Insight / Mood / Work / Life）、和纸胶带图钉与沉浸式杂志排版。
3. **五阶认知演进体系 (L0–L4 Cognitive Hierarchy)**：原始小票 (L0) ➔ 每日日志 (L1) ➔ 习惯与准则 (L2) ➔ 心智模型 (L3) ➔ 核心原则 (L4)。
4. **每周记忆小结与维护中心 (Weekly Memory Digest & CRUD)**：自然周记忆切片沉淀、认知分布看板、支持一键增删改查与导出标准 Markdown 周报。
5. **本地优先与 GitHub 私有云静默归档 (Local-First & Silent Git Sync)**：无中心化数据库，纯前端 LocalStorage 秒级就绪，防抖自动推送至用户个人私有 GitHub 仓库，并在窗口关闭（`beforeunload`）时提供 keepalive 提交保障。
