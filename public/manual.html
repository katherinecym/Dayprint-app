Overview · Core Design

Local-First Architecture & Complete Data Ownership

Most personal thoughts get lost across Slack threads, quick scratchpads, and phone memos. When you actually need them later—for a promotion review, an architecture decision, or recalling how you solved a tough bug three months ago—they are nearly impossible to find. Dayprint provides a focused, local-first workspace that connects straight to your private GitHub repository as plain Markdown files.

Storage Model

Direct GitHub Sync

No central databases and no proprietary cloud formats. Every note card, daily slip, and relationship compiles into standard Markdown files in your private GitHub vault.

  • Direct client calls to GitHub REST API
  • Personal token stored only in local browser
  • Full compatibility with local Obsidian vaults
Visual Craft

Tactile Paper & Ink

Moving past cold glass interfaces. Dayprint uses warm Morandi paper tones, mechanical keystroke sounds, physical torn-paper edges, and watercolor wash glow.

  • Clean paper textures and warm background
  • 5 watercolor mood washes for daily reflection
  • Realistic thermal receipt sawtooth cuts
Cognition

Structured Knowledge

Beyond random scratchpads. Dayprint organizes knowledge across a vertical L0~L4 cognitive pyramid paired with a horizontal semantic network graph.

  • From L0 raw scratchpads to L4 core beliefs
  • Clickable source provenance linking back to origins
  • Automatic latent link compiler

Calibration · Cognitive Ledger

Tab 2: Cognitive Ledger (Memory OS)

The primary read-and-write calibration workbench in Dayprint. Here, casual fragments are organized into five cognitive layers with visible confidence scores, bilingual readiness indicators, and clickable source provenance.

Layered Hierarchy

L0~L4 Cognitive Pyramid

Groups thoughts from L0 Raw Stream up to L1 Wins, L2 Habits/SOPs, L3 Mental Models, and L4 Core Beliefs. Includes the AI Distill tool to synthesize high-order principles.

  • Sorted by calibration need (items needing edits rank first)

Traceability

Source Provenance Chain (source_ids)

Higher-level principles (L3/L4) explicitly display "Derived from N notes". Click to expand and highlight the exact historical notes where the insight was originally recorded.

  • Clickable provenance back to origin daily notes
  • Inline editing of bilingual text and topics directly on cards
  • Exports standard frontmatter compatible with Obsidian
Relational Map · Knowledge Graph

Tab 3: Knowledge Graph

The horizontal relational network topology. Explore concepts through an interactive force-directed canvas with auto-linking compilers, or inspect degree centrality via compact read-only Topology Capsules.

Interactive Canvas

Force Graph & Auto-Link Compiler

Nodes cluster naturally by topic and wikilink affinity with physics spring forces. Clicking 'Auto-Link Graph' runs local heuristics to detect latent relationships across your vault.

  • Smooth zoom, pan, and interactive node dragging
  • Auto-Link Compiler discovers hidden semantic relationships
  • Nodes color-coded by their cognitive level
Centrality Ranking

Topology Index Capsules

The card switcher toggles to a clean 5~6 column Topology Capsule view. Stripped of body text, it ranks nodes strictly by connection count (Links) to surface hub concepts.

  • Sorted strictly by degree centrality (most links first)
  • Clean compact capsules: type + level + title + link count
  • Clicking any capsule highlights the node in the canvas
